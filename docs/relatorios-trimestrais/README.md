# Revisões Trimestrais — GEO IPOG

Diretório dedicado às revisões estratégicas trimestrais entregues a cada três meses para Ronan Maia (CEO IPOG) e Bruno Azambuja (Marketing IPOG).

## Estrutura

- `_TEMPLATE.md` — modelo canônico, copiado a cada novo trimestre.
- `YYYY-Q{N}.md` — revisão do trimestre indicado.

## Convenção de nomes

`YYYY-Q{N}.md` onde `Q{N}` é o trimestre.

Exemplos:
- `2026-Q2.md` — revisão de abril a junho de 2026 (Q2 fiscal)
- `2026-Q3.md` — revisão de julho a setembro de 2026
- `2026-Q4.md` — revisão de outubro a dezembro de 2026
- `2027-Q1.md` — revisão de janeiro a março de 2027

## Cadência

- **Frequência:** trimestral.
- **Janela de fechamento:** último domingo do último mês do trimestre às 21h00 BRT.
- **Janela de envio:** 5 dias antes da sessão de revisão estratégica agendada.
- **Audiência primária:** Ronan Maia (CEO IPOG).
- **Lead:** Alexandre Caramaschi (Head Brasil GEO).
- **Duração da sessão:** 2-3 horas (mais profunda que o checkpoint mensal).

## Pauta canônica da revisão trimestral (2-3 horas)

1. Estado do programa em uma página (15 min).
2. Análise estratégica — o que funcionou e o que não (30 min).
3. Mensuração consolidada — 12 séries temporais (30 min).
4. Re-calibração trimestral — full-grid prompt sensitivity, cohort de LLMs, dicionário de concorrentes, kit de prompts (30 min).
5. Roadmap — confirmação ou ajuste das fases seguintes (30 min).
6. Decisões executivas pedidas (15 min).
7. Expansão do programa — assessment de outras áreas IPOG (15 min).

## O que diferencia trimestral de mensal

| Dimensão | Mensal | Trimestral |
|---|---|---|
| Foco | Operacional + decisões táticas | Estratégico + recalibração |
| Profundidade | Estado vs. mês anterior | Tendência vs. baseline + projeção |
| Recalibração | Não | Full-grid prompt sensitivity + cohort de LLMs + dicionário de concorrentes |
| Mudança de roadmap | Pequenos ajustes táticos | Possível recalibração de fases |
| Duração | 60 min | 2-3 horas |
| Agregação | 4 relatórios semanais | 3 relatórios mensais |
