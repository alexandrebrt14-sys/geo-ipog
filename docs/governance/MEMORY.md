## Como atualizar esta memória

1. Toda **decisão canônica** vai para `HISTORICO-DECISOES-CANONICAS.md` no formato DC-NNN.
2. Todo **artefato novo** ou movido tem entrada nesta página com link relativo.
3. Toda **convenção** (naming, schema, KPI) tem documento próprio referenciado aqui.
4. Quando um artefato é **substituído ou descontinuado**, marcar com nota e link para sucessor; nunca remover linha sem rastreabilidade.
